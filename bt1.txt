pragma solidity ^0.8.18;  
contract Bank {  
// Mapping to store balances of each customer (address)  
mapping(address => uint256) private balances;  

// Deposit money into your account  
function depositMoney(uint256 amount) public payable {  
require(amount > 0, "Deposit amount must be greater than zero");  
balances[msg.sender] += amount;   
}  
// Withdraw money from your account  
function withdraw(uint256 amount) public {  
require(amount > 0, "Withdraw amount must be greater than zero");  
require(balances[msg.sender] >= amount, "Insufficient balance");  
balances[msg.sender] -= amount;   
}  
// Show your account balance  
function showBalance() public view returns (uint256) {  
return balances[msg.sender];  
} 
}

Step 4: Deposit money
function depositMoney(uint256 amount) public payable {
    require(amount > 0, "Deposit amount must be greater than zero");
    balances[msg.sender] += amount;
}


This function deposits money into the user's account balance.

Explanation:
- depositMoney: Function name.
- uint256 amount: Amount to deposit.
- public: Function can be called externally.
- payable: Allows the function to receive Ether.
- require(amount > 0): Checks that the deposit amount is greater than zero.
- msg.sender: Address of the person calling the function.
- balances[msg.sender] += amount: Adds the amount to that user's recorded balance.
Example:

If your balance is 500 and you deposit 200:

New balance = 500 + 200 = 700.

Remember
 msg.sender means the wallet address of the person who called the function.
Step 5: Withdraw money
function withdraw(uint256 amount) public {
    require(amount > 0, "Withdraw amount must be greater than zero");
    require(balances[msg.sender] >= amount, "Insufficient balance");
    balances[msg.sender] -= amount;
}


This function withdraws money from the user's recorded balance.

Explanation:
- withdraw: Function name.
- amount: Amount to withdraw.
- First require(): Checks that the withdrawal amount is greater than zero.
- Second require(): Checks that the user has sufficient balance.
- balances[msg.sender] -= amount: Subtracts the amount from the user's balance.
Example:

Current balance = 700

Withdrawal = 200

New balance = 700 - 200 = 500.

5. Important viva questions and answers

Mapping is a data structure that stores information in key-value pairs.

To store the balance of each customer using their wallet address.

Q3. What is msg.sender?

Q4. What is payable?

Q5. What is Ether?

Ether (ETH) is the cryptocurrency used on the Ethereum blockchain.

Q6. What is the difference between public and private?
- Public: Accessible externally.
- Private: Not directly accessible externally.
Q7. Why do we use require()?

To check conditions and stop invalid transactions.

Q8. Why is view used in showBalance()?

Because it only reads the balance and does not modify it.

Q9. What happens if the deposit amount is zero?

The transaction fails because of the require() condition.

Q10. Can two users have separate balances?

Yes. Each user's wallet address is used as a separate mapping key.
6. Important practical concept: One limitation in your code
Your depositMoney() function is marked payable, but the code does not check whether the actual Ether sent matches the amount entered.

Also, your withdraw() function only subtracts from the internal mapping. It does not transfer Ether back to the user's wallet.

So this is a basic balance-management demonstration, not a complete secure banking contract.
